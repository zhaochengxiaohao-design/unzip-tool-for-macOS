# 万能解压 macOS 版

简体中文 | [English](README.md)

面向 Apple Silicon Mac 的原生 SwiftUI 解压工具。万能解压根据文件内容识别压缩格式，安全处理解压任务，并支持不打开主窗口的 Finder 右键解压。

## 功能亮点

- 根据文件内容识别格式，不依赖文件扩展名。
- 支持 ZIP、7Z、RAR/RAR5、TAR、GZ、BZ2、XZ、`tar.gz`、`tar.bz2`、`tar.xz` 及常见分卷压缩包。
- 支持加密压缩包，密码不会写入进程参数、日志、偏好设置或文件。
- 支持多任务队列，并将组合压缩格式完整展开到最终内容。
- 提供两种输出模式：
  - 在选定目录中为每个压缩包创建独立文件夹。
  - 直接解压到压缩包所在目录；选择该模式时隐藏自定义路径选项。
- 文件冲突可按任务选择覆盖、跳过、保留两者或取消。
- 支持 Finder 的“打开方式 → 万能解压”和“服务 → 使用万能解压”。
- Finder 触发的任务静默运行、不抢焦点，完成后自动退出；仅需要密码时显示窗口。
- 根据 macOS 当前语言自动切换简体中文或英文。

## 构建

要求：

- Apple Silicon Mac
- macOS 14 或更高版本
- Swift 6 Command Line Tools
- 可联网下载官方 7-Zip 26.02 macOS 二进制文件

```bash
./scripts/build_app.sh
```

脚本会运行核心检查和真实解压引擎集成测试，构建 arm64 发布版，执行 ad-hoc 签名，刷新 Finder 注册，并生成：

- `outputs/万能解压.app`
- `outputs/万能解压-macOS-arm64.zip`
- `outputs/万能解压-源代码.zip`

由于未使用 Apple Developer ID，应用未经过公证。如需公开分发，请增加 Developer ID 签名和 Apple 公证流程。

## 安全策略

- 使用 7-Zip 技术列表预检压缩包条目。
- 拒绝绝对路径、`..` 越界、危险符号链接和特殊设备文件。
- 在已知展开大小时检查磁盘空间，并预留 100 MB 安全余量。
- 始终先解压到目标位置旁的隐藏临时目录，验证成功后再移动文件。
- 任务取消、密码错误、文件损坏或解压失败时清理临时数据。
- 永不持久化保存压缩包密码。
