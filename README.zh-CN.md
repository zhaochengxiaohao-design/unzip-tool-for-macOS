# 万能解压 macOS 版

简体中文 | [English](README.md)

面向 Apple Silicon Mac 的原生 SwiftUI 压缩与解压工具。万能解压根据文件内容识别压缩格式，也可创建常用格式压缩包，安全处理任务，并支持不打开主窗口的 Finder 右键解压。

## 直接下载

[**⬇ 下载万能解压 v1.5.0 macOS 版**](https://github.com/zhaochengxiaohao-design/unzip-tool-for-macOS/releases/download/v1.5.0/Universal-Extractor-v1.5.0-macOS-arm64.zip)

适用于 Apple Silicon、macOS 14 或更高版本。这个 ZIP 已包含完整 App 和内置解压引擎，不需要另外下载运行组件或源码包。

下载后解压 ZIP。首次启动时请按住 Control 点击“万能解压”，选择“打开”，再确认 macOS 提示。公开构建采用 Hardened Runtime 的 ad-hoc 签名，但没有 Developer ID 签名或 Apple 公证。不要全局关闭 Gatekeeper，也不要全局移除 quarantine 属性。

## 功能亮点

- 根据文件内容识别格式，不依赖文件扩展名。
- 支持 ZIP、7Z、RAR/RAR5、TAR、GZ、BZ2、XZ、`tar.gz`、`tar.bz2`、`tar.xz` 及常见分卷压缩包。
- 可创建 7Z、ZIP、TAR、`tar.gz`、`tar.bz2`、`tar.xz`，以及单文件 GZIP、BZIP2、XZ 压缩包。
- 支持压缩级别、输出重名自动编号、进度、取消及 7Z/ZIP 密码保护。RAR 格式专有，因此不支持创建。
- 支持加密压缩包，密码不会写入进程参数、日志、偏好设置或文件。
- 支持多任务队列，并将组合压缩格式完整展开到最终内容。
- 提供两种输出模式：
  - 在选定目录中为每个压缩包创建独立文件夹。
  - 直接解压到压缩包所在目录；选择该模式时隐藏自定义路径选项。
- 文件冲突可按任务选择覆盖、跳过、保留两者或取消。
- 支持 Finder 的“打开方式 → 万能解压”和“服务 → 使用万能解压”。
- Finder 触发的任务静默运行、不抢焦点，完成后自动退出；仅需要密码时显示窗口。
- 根据 macOS 当前语言自动切换简体中文或英文。

## 构建

要求：

- Apple Silicon Mac
- macOS 14 或更高版本
- Swift 6 Command Line Tools
- 可联网下载官方 7-Zip 26.02 macOS 二进制文件

```bash
./scripts/build_app.sh
```

脚本会运行核心检查和真实解压引擎集成测试，构建 arm64 发布版，执行 ad-hoc 签名，刷新 Finder 注册，并生成：

- `outputs/万能解压.app`
- `outputs/Universal-Extractor-v1.5.0-macOS-arm64.zip`
- `outputs/Universal-Extractor-v1.5.0-Source.zip`
- `outputs/SHA256SUMS.txt`

构建过程会使用固定的 SHA-256 值分别校验官方 7-Zip 26.02 下载归档和解包后的 `7zz` 可执行文件，并为 App 及内置引擎启用 Hardened Runtime 后执行 ad-hoc 签名。

## 安全策略

- 以流式方式预检完整的 7-Zip 技术列表，并限制条目数、单行长度和整数溢出。
- 拒绝绝对路径、`..` 越界、特殊文件，以及无法证明始终位于隔离输出树内的符号链接或硬链接。
- 对文件名禁用通配符扩展；创建压缩包时保存符号链接本身，不跟随读取外部目标内容。
- 在识别、测试和解压前快照源压缩包与分卷，避免文件在安全检查阶段之间被替换。
- 在解压前和解压期间检查磁盘空间；即使展开大小未知，也会保留安全余量。
- 始终先解压到目标卷上的私有临时目录；直接解压使用回滚区，合并失败不会丢弃原有文件。
- 拒绝可被其他本机用户改名、注入或替换的目标路径链与已有合并目录。
- 任务取消、密码错误、文件损坏或解压失败时清理临时数据；若回滚失败则保留恢复数据，不删除唯一副本。
- 将下载压缩包的 macOS quarantine 元数据传播到解压出的可执行内容。
- 永不持久化保存压缩包密码。
- 创建压缩包时通过受控标准输入传递密码，不写入命令参数，并拒绝控制字符及超长密码；因 7-Zip 的 ZIP 兼容限制，ZIP 密码限英文、数字和半角符号，7Z 支持中文密码。
- 禁止将输出压缩包保存到正在压缩的文件夹内部，避免递归包含输出。
- 压缩前以不跟随符号链接的方式检查输入，估算每条目、长路径及 TAR 头开销，写入期间持续监测空间；完成后先验证压缩包，再从目标卷上的私有暂存目录排他发布，绝不覆盖已有同名文件。

压缩包始终属于不可信输入。内置 7-Zip 解析器会在本地、非沙箱进程中运行；以上防护会降低风险，但不能保证隔离所有未来可能出现的解析器漏洞。发现疑似漏洞时，请按照 [SECURITY.md](SECURITY.md) 私密报告。

待压缩项目会在安全检查后从原位置读取。如果其他进程在压缩期间修改这些文件，生成的归档可能反映并发变化；输出仍只会在私有暂存、空间监测、完整验证全部成功后发布。
